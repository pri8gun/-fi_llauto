# Smartsheet Autofill

Автоматическая отправка формы Smartsheet "Woodfibre Daily Head Count"
каждый день в 7:30 по времени Ванкувера, но **только** в дни рабочей
ротации, заданные в `scripts/autofill.py` (переменная `WORK_RANGES_2026`).

## Установка

### 1. Создайте репозиторий на GitHub

Загрузите туда все файлы из этой папки, сохранив структуру:

```
.github/workflows/autofill.yml
scripts/autofill.py
requirements.txt
```

**Если ваш аккаунт ограничен только публичными репозиториями** (например,
из-за региональных ограничений GitHub) — это нормально для данного проекта:
имя и все личные данные хранятся не в коде, а в секретах репозитория (см.
шаг 3), которые никогда не отображаются публично, даже в публичном
репозитории.

### 2. Настройте отправку email (Gmail)

1. Включите двухфакторную аутентификацию на вашем Google-аккаунте (если
   ещё не включена) — без этого пароли приложений не работают.
2. Перейдите на https://myaccount.google.com/apppasswords
3. Создайте новый "пароль приложения" (App password), название можно любое,
   например "Smartsheet Autofill".
4. Скопируйте сгенерированный 16-значный пароль — он понадобится ниже.

Если вы используете не Gmail, а другой почтовый сервис — узнайте его SMTP
адрес и порт (обычно 587) и используйте соответствующие настройки.

### 3. Добавьте секреты в репозиторий GitHub

В репозитории: **Settings → Secrets and variables → Actions → New repository
secret**. Создайте три секрета:

| Имя | Значение |
|---|---|
| `SMTP_USER` | ваш email (например `you@gmail.com`) |
| `SMTP_PASS` | пароль приложения из шага 2 (16 символов, без пробелов) |
| `NOTIFY_EMAIL` | email, куда присылать уведомления (можно тот же) |
| `WORKER_NAME` | имя, которое будет вписано в поле Name формы |

### 4. Проверьте расписание

По умолчанию GitHub Actions запускает флоу в 14:30 и 15:30 UTC каждый день.
Скрипт сам определяет, какой из двух запусков соответствует 7:30 утра по
Ванкуверу (с учётом перехода на летнее/зимнее время), и выполняет реальную
работу только один раз.

### 5. Тестовый запуск вручную

Перейдите на вкладку **Actions** в репозитории → выберите workflow
"Smartsheet Autofill" → **Run workflow** — это запустит скрипт прямо сейчас,
не дожидаясь расписания. Обратите внимание: если сегодняшняя дата не входит
в рабочие диапазоны, или сейчас не 7 утра по Ванкуверу, скрипт просто
завершится без действий — это нормальное поведение, а не ошибка.

Чтобы протестировать саму логику заполнения формы независимо от даты/времени,
временно закомментируйте проверки в функции `main()` в `autofill.py`, запустите
вручную, а затем верните проверки обратно.

## Обновление рабочих дат на будущее

Откройте `scripts/autofill.py`, найдите `WORK_RANGES_2026` и обновите
диапазоны на новый период, когда текущий график закончится.

## Просмотр логов

Вкладка **Actions** → выберите конкретный запуск → откроется полный лог
выполнения, включая любые ошибки Playwright.

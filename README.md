# Smartsheet Autofill

Автоматическая отправка формы Smartsheet "Woodfibre Daily Head Count" каждый день в 7:30 по времени Ванкувера, но только в дни рабочей ротации.

## Что уже настроено

GitHub Actions запускает workflow дважды в день (14:30 и 15:30 UTC), чтобы покрыть переход между PST/PDT. Скрипт сам проверяет локальное время Vancouver и рабочие диапазоны.

## Секреты GitHub

В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret** и создайте:

- `WORKER_NAME` — имя для поля Name в форме
- `SMTP_USER` — Gmail-адрес отправителя
- `SMTP_PASS` — пароль приложения Google
- `NOTIFY_EMAIL` — адрес для уведомлений

Не записывайте эти значения в файлы репозитория.

## Ручной тест

Откройте **Actions → Smartsheet Autofill → Run workflow**.

Важно: обычный ручной запуск всё равно подчиняется проверкам даты и локального часа в скрипте. Если сегодня не рабочий день или локальное время не 07:00, форма не будет отправлена.

## Рабочие диапазоны 2026

Диапазоны находятся в `scripts/autofill.py` в переменной `WORK_RANGES_2026`.
